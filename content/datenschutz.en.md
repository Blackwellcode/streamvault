## Note

This is an English translation provided for convenience. The German version is legally binding.

## 1. Collection and storage of data
When this system is used, access data (IP address, time of access, pages requested) is recorded in local log files to keep the system secure and running without disruption.

## 2. User accounts
For registered users, the username, password hash and role membership are stored in the local SQLite database.

## 3. Disclosure to third parties
Personal data is not disclosed to third parties.
